# Exercícios de Java

Repositório desenvolvido durante meus estudos de Java, reunindo exercícios práticos para desenvolver e reforçar os fundamentos da linguagem e da programação orientada a objetos.

## Conteúdos praticados

Durante os exercícios foram trabalhados:

* Declaração e atribuição de variáveis
* Tipos de dados (`int`, `double`, `boolean` e `String`)
* Entrada de dados utilizando `Scanner`
* Saída de dados com `System.out.println()` e `System.out.printf()`
* Concatenação de textos e variáveis
* Especificadores de formato, como `%.2f` e `%.1f`
* Operadores aritméticos (`+`, `-`, `*`, `/`, `%`)
* Operadores relacionais (`==`, `!=`, `>`, `<`, `>=`, `<=`)
* Operadores lógicos
* Operador de negação (`!`)
* Estruturas condicionais `if`, `else` e `else if`
* Estruturas de repetição `for`, `while` e `do-while`
* Estrutura de seleção `switch`, `case`, `break` e `default`
* Criação e utilização de classes
* Criação e instanciação de objetos
* Acesso e atribuição de atributos de objetos
* Cálculo de médias
* Validação de dados de entrada
* Contagem de registros utilizando variáveis de controle
* Tratamento do `Scanner` ao alternar entre entrada numérica e texto
* Organização do código em diferentes classes e pacotes

## Exercícios desenvolvidos

Os exercícios incluem exemplos de:

* Aplicação de desconto em produtos;
* Identificação de números pares e ímpares;
* Criação de menus utilizando `do-while` e `switch`;
* Criação e utilização de objetos da classe `Pet`;
* Cadastro e classificação de produtos de acordo com o preço;
* Cadastro de usuário com nome e ano de nascimento;
* Sistema de cadastro de alunas, com registro de notas, cálculo de média, aprovação ou reprovação, validação das notas e contagem de alunas cadastradas.

## Tecnologias e ferramentas

* Java
* IntelliJ IDEA
* Git
* GitHub

## Objetivo

O objetivo deste projeto é colocar em prática os fundamentos de Java por meio de exercícios progressivos, desenvolvendo a lógica de programação, a familiaridade com a linguagem e os primeiros conceitos de orientação a objetos.
